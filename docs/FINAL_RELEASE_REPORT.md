## 已知限制

普通驾车参考距离不代表货车实际可通行路线，也不考虑货车限高、限宽、限重、禁行和车牌政策。多目的地必须拆分，程序不自动排序。WPS 依赖目标机 COM 注册。Key 绑定当前 Windows 用户，每台电脑需重新保存。缓存和可信地址库备份可能包含业务地址，应受控保存。正式版已在 Windows 11 实机验收，但不宣称覆盖所有 Office/WPS/Windows 版本；Windows 10 尚未完成专项实机验证。

## 首次使用步骤

1. 完整解压正式 ZIP，保留 EXE、`_internal` 和五个运行目录，不要在 ZIP 内直接运行。
2. 在 Windows 10 或新电脑首次使用时，先复制业务文件并只处理副本。
3. 双击 EXE，在“API与设置”中用当前 Windows 用户重新保存高德 Web 服务 Key。
4. 检查 Excel/WPS 是否显示已安装；连接测试会产生少量真实请求，按业务需要执行。
5. 选择业务文件副本，核对工作表、表头、字段映射和 Office 引擎后运行，并人工复核首批结果。
