# TASK-GITHUB-002 任务结果

- 任务名称：建立自动上传与在线审核流程（固定总指挥审核通知）
- 任务分支：`task/TASK-GITHUB-002-review-workflow`

## 用户原始需求

永久加入交给总指挥审核的固定通知：审核文件推送后等待当前 PR HEAD 的 Actions，自动读取全部真实字段，并把无占位符通知放在 Codex 最终回复最末尾。

## 实际实现

- 安全扫描对所有当前差异执行个人数据规则，不再根据测试或合成关键词豁免。
- 安全扫描检查任务分支每个提交中发生变更的文本文件，发现删除前的敏感内容时阻止推送。
- 安全扫描默认阻止普通任务新增或修改图片与 PDF，并从分支历史发现后续已删除的二进制文件。
- 二进制历史命中只显示规则、文件路径和短 Commit，不读取或输出文件内容。
- finalize_task.ps1 使用 REVIEW_CONTEXT.json 提供任务目标、影响、风险和合并建议，只写入实际 Git、测试与扫描证据。
- 增加非 GitHub 流程任务的仅渲染模拟模式与自动化测试。
- 版本化审核状态统一指向 Pull Request 当前 HEAD 的 Checks 页面，不记录会随提交过期的 Actions 运行编号。
- 按当前 Pull Request 审核范围重新生成审核材料。
- finalize_task.ps1 在最终审核文件推送后核对 PR 当前 HEAD，等待该 HEAD 的 Actions 完成，并自动采集仓库、PR、运行、测试、安全和保护状态。
- 增加离线通知证据模式和专项测试，验证真实字段、审核路径、无占位符、未完成拒绝输出及失败状态不误报。
- AGENTS.md、任务模板和审核流程 README 固定要求完整通知位于 Codex 最终回复最末尾。

## 设计取舍

- 提交历史只扫描相对基础分支新增或修改过的文本和受限二进制文件，避免把 master 既有已审计文件误判为本任务新增风险。
- 任务专属叙述保存在版本化 JSON 上下文中，便于复核和重复生成。
- 仅渲染模式不连接 GitHub、不提交或推送，只用于验证报告生成通用性。
- 通知专项测试使用显式离线证据文件，不连接 GitHub；正常完成流程只能读取 GitHub、Git、pytest 和安全扫描真实结果。
- 本轮不拆分 finalize_task.ps1，不新建复杂 PowerShell 模块，避免扩大审核流程风险。
