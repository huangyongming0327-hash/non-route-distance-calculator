# TASK-GITHUB-002 任务结果

- 任务名称：建立自动上传与在线审核流程
- 任务分支：`task/TASK-GITHUB-002-review-workflow`

## 用户原始需求

为后续 Codex 任务建立统一流程：从最新 master 创建独立分支，完成离线测试、安全扫描和审核材料，显式提交并推送任务分支，创建或更新 Pull Request，把 PR 地址写回固定审核入口，等待人工审核。

## 实际实现

- 建立根目录长期规则 `AGENTS.md`。
- 建立固定审核材料结构、模板、固定入口和本任务审核目录。
- 建立任务初始化、任务结束、安全扫描和审核材料校验脚本。
- 建立 GitHub Issue、PR 模板与 Windows 离线验证 Actions。
- 建立 Codex 任务提示模板和 master 分支保护说明。
- 修正文档中的 Public 仓库当前状态，同时保留历史 Private 事实。
- 本文件只记录流程与文档变更；最终测试、提交、PR 和 Actions 结果由自动化回写并以在线页面为准。

## 未实现内容

- 不自动合并 Pull Request。
- 不自动开启严格分支保护。
- 不创建或移动标签。
- 不创建新正式版本或 GitHub Release。
- 不修改既有运距计算业务规则。

## 设计取舍

- PR 默认创建为草稿，为用户和总指挥保留独立审核环节。
- 暂存采用文件白名单和逐路径 `git add -- <path>`，禁止 `git add -A`。
- 任何测试、安全扫描或审核完整性检查失败都会停止。
- GitHub Actions 只运行离线测试，不使用真实 Key、真实 API 或真实 Office COM。

## 业务口径

是否修改既有业务口径：否。

## 合并建议

待全部本地验证和 GitHub Actions 成功后，由总指挥独立审核决定；自动化不会合并。
