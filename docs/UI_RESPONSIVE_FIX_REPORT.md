## 页面修改

### 运距计算

- 保留输入 Excel、输出目录、工作表、表头行、字段映射、保存引擎、运行模式、强制重查和字段确认。
- 前 10 行只读预览、处理进度、开始/暂停/继续/停止、打开结果/目录/日志统一放在计算页。
- 页面使用可纵向滚动的 `QScrollArea`；横向滚动为 0，小屏幕不会把控件压到不可读。
- 下拉框不再使用固定宽/高，随系统字体和 Qt 尺寸策略调整。

### 地址确认

- 完整保留刷新、重新解析、使用原始/高德标准地址、保存修正地址、确认、标记无效、批量确认、筛选、导出和导入。
- 进入页面会从现有 SQLite 可信地址库自动刷新；不解析新地址，不发出 HTTP。
- 无选中行时，6 个单条操作按钮禁用；选中后自动启用。导入、导出、刷新和批量操作不依赖选中行。
- 导入仍显示成功数、跳过数和失败数，然后自动刷新。
- `Excel城市` 和 `Excel原始详细地址` 保持只读；仅 `用于查询的修正地址` 可编辑。
- 查询地址变更时即时显示黄色提示；保存后仍明确显示“需要重新解析”。
- 确认状态和风险合并可读展示；高可信为绿色，建议复核为黄色，禁止自动算路和城市冲突为红色。
- 表格提供横向和纵向滚动条，长地址不再挤压整个窗口。

### API 与设置

- Key 输入、保存、删除、连接测试、持久化状态和普通驾车接口状态集中到独立页。
- 开发/测试模式和普通驾车缓存清理作为低频设置移到该页。
- Key 读写仍完全使用现有 `SecureKeyStore`；没有新增明文配置或日志。

## 布局与高 DPI

- 主容器使用 `QTabWidget`，页内使用 `QVBoxLayout`/`QGridLayout`/`QFormLayout`。
- 没有 `setFixedHeight` 或 `setMaximumHeight` 布局限制。
- 表格使用 `QSizePolicy.Expanding`；输入框和下拉框使用 `Expanding/Preferred`。
- 多行说明文字启用自动换行。
- Qt 6 使用原生高 DPI，明确设置 `PassThrough` 缩放四舍五入策略；没有手工二次缩放字体或控件。
