# 非线路运距计算工具原型设计

文档日期：2026-07-20  
版本：0.5.0  
阶段：TASK-004R

## 范围

原型验证“工作簿预览与映射 → 非线路报价精确筛选 → 地址校验/地理编码 → 高德普通驾车 v5 → 车型无关缓存 → 检查点 → Excel/WPS 安全写回 → 重开验证”。

不包含最终 GUI 美化、EXE、PDF、正式发布、多目的地排序或货车通行判断。

## 界面

- 标题：非线路运距计算工具 V1.0 — 高德普通驾车距离版。
- 顶部风险条：普通驾车参考距离，不代表货车实际可通行路线。
- API：安全保存/删除 Key、脱敏状态、连接测试、普通驾车可用状态和实际 HTTP 调用数。
- 工作簿：输入、输出、工作表、表头检测、字段映射和前 10 行只读预览。
- 车型：可选映射；不参与查询。
- 模式：正式普通驾车、本地校验；mock 位于默认隐藏的开发/测试设置。
- 控制：暂停、继续、停止、打开结果、打开文件夹、日志、强制刷新和清除路线缓存。

## 分层

- `src/amap`：HTTP、错误、真实地理编码、普通驾车、mock 和米制换算。
- `src/application`：业务处理器、任务控制和工作簿运行器。
- `src/cache`：SQLite WAL、地理编码/路线/任务/行结果。
- `src/workbook`：只读预览、动态列规划、COM 写回和验收。
- `src/office`：Excel/WPS 专属辅助进程、PID 归属和重开验证。
- `src/security`：Credential Manager / DPAPI / 仅内存 Key 存储。
- `src/ui`：PySide6 原型。

## 核心不变量

- 只处理报价类型精确等于“非线路报价”的行。
- 输入文件不覆盖，源指纹在任务结束时复核。
- 正式 API 失败不返回 mock 距离。
- 正式路线键不含行号或车型。
- 普通驾车结果与旧货车结果不混用。
- 成功说明总是包含普通驾车口径和货车限制免责声明。
- Office 宏、事件和更新链接不自动执行；专属进程退出后才提升最终文件。

API、缓存键和距离算法详见 `DRIVING_API_DESIGN.md`；真实验收详见 `DRIVING_REAL_TEST_REPORT.md`。
