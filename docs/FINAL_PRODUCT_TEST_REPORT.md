## 8. 已知限制

1. 普通驾车参考距离不代表货车实际可通行路线。
2. 不考虑货车限高、限宽、限重、禁行和车牌政策。
3. 多目的地必须拆分，程序不自动排序。
4. WPS 依赖目标机 COM 注册。
5. Key 绑定当前 Windows 用户，每台新电脑需重新保存。
6. 地址库和缓存 JSON 可能包含业务地址，必须受控保存。
7. Windows 10 尚未专项实测，首次使用必须先用业务文件副本测试。
