# 非线路运距计算工具用户指南（草稿）

版本：TASK-005A-UI-FIX-001 待验收稿，2026-07-20

## 使用前须知

结果是高德普通小汽车推荐路线距离，仅作为非线路报价参考，不代表货车可通行。黄色表示仍有人工复核价值，红色表示冲突或不允许自动算路。

地址确认只改变本机可信地址库中“用于查询的地址”或坐标，永远不会修改原 Excel 的城市和详细地址。

## 首次准备

1. 启动工具，确认标题为“非线路运距计算工具 V1.0 — 高德普通驾车距离版”。
2. 在“API与设置”页输入高德 Web 服务 Key 并保存。Key 只存本机；请勿通过聊天发送。
3. 点击“测试连接”。成功应显示“普通驾车接口：可用”和本次实际 HTTP 调用数（通常 2）。
4. 选择 `.xlsx` 或 `.xlsm` 输入文件和输出目录。不得把输出放在 `samples/input`。
5. 确认工作表、表头行、报价类型、始发/目的城市和详细地址。车型列可选，不参与计算。

也可双击 `scripts\run_prototype.bat` 启动。脚本不要求管理员权限，不修改系统环境变量。主窗口会先显示，默认工作簿在后台只读分析；这一过程不启动 Office，也不调用高德 API。

## 页签说明

- “运距计算”包含工作簿、字段映射、运行设置、预览、进度和任务按钮。小屏幕下请使用页面右侧纵向滚动条。
- “地址确认”自动读取当前可信地址库，表格会随窗口扩展。
- “API与设置”包含 Key、接口状态、开发/测试模式和路线缓存清理。

支持 Windows 100%/125%/150% 缩放。不需要、也不建议为使用本工具而永久将 Windows 缩放改为 100%。

## 唯一地址确认

工作簿加载后，“地址确认”页显示当前可信地址库中的唯一地址，不显示全部订单行。一个地址关联多少当前工作簿订单和唯一路线会显示在末两列。

每行显示：用途、Excel 城市、Excel 原始详细地址、高德标准地址、level、经纬度、城市冲突、确认状态/风险、修正查询地址、关联订单行数和关联路线数。绿色是高可信，黄色建议人工复核，红色表示城市冲突或不允许自动算路。

常用操作：

1. 选择一行。若高德结果正确，点击“确认定位正确”。同地址以后直接复用。
2. 若需要换查询文本，可点击“使用原始地址”或“使用高德标准地址”，也可直接编辑“用于查询的修正地址”。
3. 点击“保存修正地址”。此操作会使引用旧地理编码版本的路线缓存失效，但不修改原 Excel。
4. 点击“重新解析当前地址”，取得新的高德标准地址和坐标；核对后再确认。
5. 确认无法用于算路时，点击“标记地址无效”。以后该地址会阻止自动算路。
6. “批量确认高可信地址”只处理规则已判为高可信、无城市冲突且有有效坐标的地址。
7. 勾选“仅查看未确认”可隐藏系统高可信和已人工确认地址。

未选中任何行时，重新解析、使用原始/标准地址、保存、确认和标记无效按钮会自动禁用，不会反复弹出“请先选择”错误。选中一行后这些按钮自动启用。

第 39/78 行共享一个城市冲突地址身份，确认一次会同时复用。第 272 行因 Excel 城市不同，是另一个地址身份，需要单独确认。

## Excel 待确认清单

点击“导出待确认清单”，工作簿包含：地址ID、原始城市、原始详细地址、高德标准地址、定位层级、修正查询地址、是否确认、确认备注。

- 在“是否确认”填写“是”“否”“地址无效”或“待进一步核实”。
- 如修改“修正查询地址”，导入后程序必须重新地理编码，不能直接沿用旧坐标。
- 导入按地址ID匹配，不依赖清单行号；可排序，但不要修改地址ID。
- 重复地址ID且内容一致会跳过；内容冲突会失败。
- 完成后软件显示成功、跳过和失败数量。

“导入确认结果”不需要事先选中地址行；导入完成后表格会自动刷新。

## 执行距离计算

1. 选择保存引擎：Microsoft Excel 或 WPS 表格。
2. 选择模式：
   - 普通驾车正式计算：真实调用高德或复用正式缓存；
   - 仅本地校验：只检查地址，不生成距离；
   - 模拟测试：需打开开发/测试设置，普通用户默认看不到。
3. 一般运行只计算未完成及已变更行。如需忽略路线缓存，勾选“强制重新查询全部非线路报价”。
4. 勾选风险确认后开始。可以暂停、继续或停止；停止时保存已完成检查点。
5. 完成后打开结果文件，重点检查状态和说明列。

## 状态解释

- 查询成功—普通驾车参考：真实结果，地址无需复核。
- 缓存复用—普通驾车参考：命中正式路线缓存；说明中会记录可信地址库复用。
- 查询成功—定位待复核：得到距离，但乡镇/村庄、名称匹配不足或其他证据值得复核；黄色。
- 查询成功—地址冲突待确认：表中城市与详细地址冲突；按详细地址坐标算路并标红。确认后同地址身份不再重复标红。
- 地址风险过高—未计算：仅到区县、行政区错位、坐标异常或无法提供足够证据；红色，距离为空。
- 地址无效：可信地址库中已标记无效；不计算。
- 多目的地待确认：一行含多个目的地，未计算；请拆分线路。
- 地址为空 / 详细地址定位失败 / 地址解析失败：未得到可靠坐标，未计算。
- Key无效 / 权限不足 / 额度不足 / QPS超限 / 网络连接失败 / 查询超时 / 查询失败：未生成或伪造距离。
- 用户停止：任务被安全停止。

## 缓存管理

“API与设置”页的“清除普通驾车路线缓存”只删除 `driving_real` 路线，不删除可信地址库、地理编码、历史任务、mock 或源文件。修改地址或坐标会自动删除相关路线，不需要清空全部缓存。

## 结果列

工具写入：高德普通驾车公路距离（公里）、距离查询状态、距离查询说明。若工作表已有旧货车距离列，工具保留旧列并在实际最后列追加普通驾车三列。

## 安全注意

- 不要在任务运行时手工结束工具创建的 Excel/WPS 进程。
- 不要修改或删除 `samples/input` 原样表。
- 不要把日志、凭据文件或缓存发送给无关人员。
- 人工确认代表业务判断；不能只为消除黄色提示而批量确认风险地址。
- 普通驾车结果不能表述为“货车可通行”。
