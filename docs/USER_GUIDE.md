# 非线路运距计算工具 V1.0 使用说明

本工具用于在 Excel 或 WPS 表格中，为报价类型精确等于“非线路报价”的行填写高德普通驾车参考距离。其他报价类型不会被修改，原文件也不会被覆盖。

> 重要提示：普通驾车参考距离，不代表货车实际可通行路线。本工具不考虑货车限高、限宽、限重、禁行和车牌政策，请另行核实。

## 1. 开始前准备

- 已在 Windows 11 完成实机验收。Windows 10 尚未完成专项实机验证，首次使用应先复制业务文件并用副本测试。
- 电脑需安装 Microsoft Excel 或 WPS 表格，至少安装其中一种。
- 准备一个有效的高德 Web 服务 Key。Key 只在本机保存，请不要通过聊天、邮件或截图发送给他人。
- 将收到的 ZIP 完整解压到一个可写目录。支持中文和空格路径，例如 `D:\办公工具\非线路运距计算工具`。
- 不要直接在 ZIP 压缩包内双击程序，也不要只复制 EXE；必须保留整个文件夹和 `_internal` 目录。
- 可以为“非线路运距计算工具.exe”创建桌面快捷方式，但不要移动单独的 EXE，也不要删除 `_internal`。

## 2. 第一次启动

1. 双击“非线路运距计算工具.exe”。不需要安装 Python，也不需要管理员权限。
2. 打开“API与设置”页签。
3. 在 Key 输入框中粘贴高德 Web 服务 Key，点击“保存 Key”。
4. 确认界面显示“已存 Key”，且保存位置为 Windows 凭据管理器或 Windows DPAPI。
5. 点击“测试连接”。连接测试最多发出 2 个成功请求；看到“普通驾车接口：可用”后即可开始。

每台新电脑都要重新输入 Key。凭据与当前 Windows 用户绑定，不能通过复制 `config` 目录迁移到另一台电脑。

可信地址库和普通驾车缓存也存放在当前便携目录。每台电脑通常只需首次导入一次；关闭程序或电脑后数据不会丢失。只有重新解压到全新目录或删除 `cache` 后才需要重新导入。未导入缓存时程序仍可使用，但会按需重新调用高德 API，并在本机逐步积累新缓存。

## 3. 完成一次运距计算

### 第一步：选择 Excel 文件

在“运距计算”页点击“选择 Excel 文件”，选择 `.xlsx` 或 `.xlsm` 文件。程序会在选择后读取工作表、自动识别表头和字段；启动时不会自动打开或扫描任何样表。

### 第二步：确认工作表和字段

1. 查看“工作表”和“表头行”是否正确。
2. 如需重选，选择工作表后点击“自动检测表头/字段”。
3. 逐项确认报价类型、始发城市、始发详细地址、目的城市和目的详细地址。
4. 车型字段可不选，且不参与普通驾车距离计算。
5. 查看前 10 行只读预览，确认列没有错位。

### 第三步：选择 Excel 或 WPS

- 已安装 Microsoft Excel 时，优先选择“Microsoft Excel”。
- 只安装 WPS，或业务流程指定 WPS 时，选择“WPS 表格”。
- 如果界面显示“未检测到”，请先关闭本工具，修复或重新安装对应办公软件后再试。

程序只操作自己新建的隔离 Office 进程，不会主动关闭用户已经打开的 Excel 或 WPS 窗口。

### 第四步：选择输出位置

选择文件后，默认输出到原 Excel 所在目录；也可点击“选择输出目录”另行指定。结果文件名带时间戳，原文件永不覆盖。

### 第五步：开始处理

1. 保持“强制重新查询”不勾选，可优先复用已有缓存并减少 API 请求。
2. 默认运行模式应为“普通驾车正式计算”。模拟测试模式只在开发模式中显示，不得用于业务。
3. 勾选“我已确认字段映射”。
4. 点击“开始处理”。处理期间可暂停、继续或安全停止。

### 第六步：打开结果

处理完成后，完成摘要会显示处理行数、需要留意的行、复用已有结果的行数以及结果文件完整路径。点击“打开结果”或“打开结果文件夹”。

## 4. 结果文件说明

程序只处理报价类型精确等于“非线路报价”的行。其他报价类型行保持不变。

结果文件固定为有效 `.xlsm`，新增或复用以下三列：

1. 高德普通驾车公路距离（公里）
2. 距离查询状态
3. 距离查询说明

成功结果的说明中会保留：普通驾车参考距离，不代表货车实际可通行路线。

程序会尽量保留原工作簿的公式、图片、筛选、隐藏行、条件格式、工作表结构和 VBA 内容；不会自动运行原文件中的 VBA。输出前后请保留原文件作为备份。

## 5. 地址异常处理

打开“地址确认”页签。原 Excel 的城市和详细地址始终只读；“用于查询的修正地址”只影响高德查询，不会修改原 Excel。

- 刷新唯一地址清单：重新读取可信地址库和当前工作簿中的唯一地址。
- 仅查看未确认：隐藏已经确认的地址。
- 重新解析当前地址：使用当前查询地址重新获取高德坐标，会调用高德接口。
- 使用原始地址：把查询地址恢复为原 Excel 地址。
- 使用高德标准地址：把查询地址改为高德返回的标准地址。
- 保存修正地址：保存人工修改的查询地址，随后还应重新解析并检查坐标。
- 确认定位正确：人工认可当前标准地址和坐标。
- 标记地址无效：阻止该地址自动计算。
- 批量确认高可信地址：只确认系统判定为高可信的地址。

城市冲突、低精度定位、多目的地文本或地址无效时，不要盲目确认。应结合地图和业务资料核对。

## 6. 导出和导入地址确认清单

### 导出

1. 在“地址确认”页点击“导出待确认清单”。
2. 将生成的 `.xlsx` 文件交给业务人员核对。
3. 不要删除程序导出的说明行和字段；可在表内填写确认结果、修正地址和备注。

### 导入

1. 点击“导入确认结果”，选择程序导出的清单或同格式文件。
2. 程序会自动在前 20 行识别表头。
3. 完成提示会分别显示成功、跳过和失败数量。
4. 失败项会显示 Excel 实际行号和原因；按提示修正后可再次导入。

## 7. 备份和迁移可信地址库、缓存

在“API与设置”页的“数据备份与缓存”区域操作：

- “导出可信地址库”只导出已确认可信的地址记录。
- “导入可信地址库”可在新电脑恢复可信地址。
- “导出普通驾车缓存”导出正式普通驾车地理编码和路线缓存，不包含任务历史、源文件路径、Key 或行级结果。
- “导入普通驾车缓存”可减少新电脑上的重复查询。

备份文件可能包含业务地址，必须保存在受控目录，不要放入公共网盘或发送给无关人员。迁移 Key 时不要复制凭据文件，应在新电脑重新输入。

关闭程序和电脑不会清除已经导入的可信地址库或缓存。若把整个已使用目录复制到另一台电脑，业务数据文件也会随目录一起复制，但 Key 仍须由目标电脑当前 Windows 用户重新保存。为降低业务地址扩散风险，优先在新电脑完整解压通用空包，再通过受控的 JSON 备份导入可信地址库和缓存。

## 8. Excel 文件被占用怎么办

- 先保存并关闭要处理的原文件，再重新开始。
- 检查是否有同名文件正在 Excel、WPS、预览窗格、同步盘或杀毒软件中占用。
- 如果结果文件被占用，关闭结果文件后重新处理；程序不会覆盖原文件。
- 不要结束用户已有的 Excel/WPS 进程。若 Office 辅助进程异常残留，请先关闭本工具，再通过任务管理器仅结束本次新建且无窗口的进程。

## 9. 常见问题

### 双击后没有窗口

确认已完整解压，并保留 EXE 与 `_internal` 的相对位置。查看 `logs\startup_error.log` 和 `logs\startup.log`；将日志交给维护人员时先检查是否含业务路径。

### Key 保存后仍显示未保存

确认当前 Windows 用户有权使用凭据管理器。可删除后重新保存；不要手工编辑 `config` 文件。

### 连接测试失败

检查网络、Key 是否启用了高德 Web 服务、配额和安全设置。连接测试会产生少量真实请求。

### 工作表或字段识别错误

选择正确工作表，设置实际表头行，再点击“自动检测表头/字段”；开始前必须逐项确认映射。

### 无法保存结果

关闭被占用的输入或输出文件，确认输出目录可写，并检查 Excel/WPS 是否已正确安装和注册。

### 某些行没有距离

检查报价类型是否精确为“非线路报价”，再查看“距离查询状态”和“距离查询说明”。地址无效、多目的地、城市冲突或低精度定位可能需要人工确认。

### 为什么普通驾车不能代表货车路线

高德普通驾车路线面向普通机动车参考，不能保证识别货车限高、限重、禁行时段、车型尺寸、危险品限制或临时交通管制。因此结果只可作为非线路报价参考。

## 10. 文件夹说明与隐私

- `config`：本机 DPAPI 凭据的备用存储；不得复制给他人。
- `cache`：可信地址库和路线缓存。
- `logs`：启动、连接和处理审计日志。
- `outputs`：默认备份或手工指定的输出位置之一。
- `temp`：本次处理的工作副本和 Office 辅助文件。

公开发布包初始状态不包含真实 Key、业务 Excel、业务地址数据库、历史缓存、日志或处理结果。使用后这些目录可能产生本机业务数据，请纳入公司的备份、访问控制和清理制度。

## 11. 正式 V1.0 使用边界

- 正式 V1.0 已在 Windows 11、Microsoft Excel 和本机已注册的 WPS 表格完成验收，但不代表覆盖所有 Office、WPS 和 Windows 版本。
- 多目的地必须先拆分为单一目的地，程序不会自动排序或选择路线。
- WPS 依赖目标电脑的 COM 注册；如显示未检测到或保存安全校验失败，请先修复 WPS 或改用 Microsoft Excel。
- 新电脑首次使用时，先完整解压、用当前 Windows 用户重新保存高德 Key，再用业务文件副本完成一轮 Excel/WPS 检测和结果核对。
