## 11. 用户第一次验收步骤

1. 将 ZIP 解压到新的中文或带空格目录。
2. 双击 EXE，确认 3 秒左右出现主窗口且没有黑色命令行窗口。
3. 打开“API与设置”，输入本机高德 Web 服务 Key 并保存。
4. 点击“测试连接”，确认普通驾车接口可用。
5. 检查 Excel/WPS 检测状态。
6. 选择一份实际 `.xlsx`，确认工作表、表头、字段和输出目录。
7. 不勾选强制重新查询，完成一次缓存优先的 Excel 处理。
8. 用 Excel/WPS 打开结果，核对原文件不变、非目标行不变、公式/图片/筛选/隐藏行正常。
9. 测试一个 `.xlsm`，确认宏不自动运行且 VBA 保留。
10. 测试地址异常确认清单导出/导入，以及可信地址库/缓存备份迁移。
