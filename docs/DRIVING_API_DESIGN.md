# 高德普通驾车 API 设计

文档日期：2026-07-20  
实现版本：0.5.0  
正式模式：`driving_real`

## 1. 目标与边界

工具仅为“非线路报价”提供普通小汽车推荐路线的参考公路距离。它不是货车路径规划，不承诺货车实际可通行，也不考虑限高、限宽、限重、禁行或车牌限制。

专业货车 `/v4/direction/truck` 因最低采购成本过高终止，不在正式调用链、失败降级链或缓存中使用。

## 2. 接口合同

地理编码使用 v3，详细地址优先；地址已经包含省市时首请求不强制传城市，只有必要时才以表中城市提示兜底。

普通驾车请求：

```text
GET https://restapi.amap.com/v5/direction/driving
origin=<lon,lat>
destination=<lon,lat>
strategy=32
cartype=0
ferry=1
alternative_route=1
output=json
key=<仅由安全凭据提供者注入>
```

实现依据：高德官方[路径规划 2.0 文档](https://lbs.amap.com/api/webservice/guide/api/newroute)。合同标识为 `amap-driving-v5-contract-2026-06-17`。

程序验证 `route` 和 `paths` 非空，只接收第一条路径；失败时返回明确状态，不使用 mock、旧驾车或货车接口补距离。

## 3. 距离单位

官方定义 `route.paths.distance` 为米。实现只保留一个换算入口：

1. 拒绝空值、非整数、负数、NaN 和无穷大；
2. 原始整数米数写入审计和路线缓存；
3. `Decimal(meters) / Decimal(1000)`；
4. `ROUND_HALF_UP` 到 `0.1` 公里；
5. 工作簿按数值写入并显示一位小数。

不再存在 paths/steps 三线路单位门、车辆参数门或工单门。

## 4. 地理编码与业务规则

- 多目的地：不调用 API，不计算。
- 地址为空：不调用 API，不计算。
- 只能到国家/省/市：阻止算路，状态“详细地址定位失败”。
- 低于道路/门牌号级但仍有可用坐标：继续算路，状态“查询成功—定位精度较低”，黄底提示人工复核。
- 城市字段与详细地址冲突：按详细地址坐标算路，状态“查询成功—地址冲突待确认”，红底提示。
- 非目标报价行：不处理、不写结果列。

每个成功说明至少包含：

> 高德普通小汽车驾车推荐路线；strategy=32；不使用轮渡。本距离不考虑货车限高、限宽、限重、禁行及车牌限制，仅作为非线路报价运距参考。

## 5. 车型

车型是可选只读业务信息。它不进入：

- HTTP 请求；
- 地理编码或路线缓存键；
- 输入变化摘要；
- 距离计算；
- 查询状态或条件格式。

车型为空或未知均正常查询。同一起终点的不同车型复用同一条路线缓存。

## 6. 缓存

正式数据库：`cache/driving_real.sqlite`。mock 继续使用独立数据库和 `mode=mock`。

路线键包含：

- 起终点经纬度（6 位小数）；
- 起终点标准地址哈希；
- `strategy=32`、`cartype=0`、`ferry=1`、`alternative_route=1`；
- API v5 合同版本；
- 两端地址清洗版本；
- 算法版本；
- `mode=driving_real`。

路线键不含 Excel 行号、车型、size 或车辆物理参数。缓存记录查询时间；强制刷新在一次运行中对每个唯一路线只重新查询一次，随后重复行复用新结果。

## 7. 工作簿列策略

正式结果三列：

1. 高德普通驾车公路距离（公里）
2. 距离查询状态
3. 距离查询说明

只有表头完整且连续时才原位复用。旧“高德货车公路距离（公里）”及其相邻状态/说明不视为普通驾车结果，程序在工作表实际最后一列之后追加新三列。

## 8. 运行、错误与安全

- 正式：v3 地理编码 + v5 普通驾车；顶部显示普通驾车风险提示。
- 本地校验：不调用 API，不生成距离。
- mock：默认隐藏在开发/测试设置，醒目标记，不能进入正式缓存。
- 连接测试：一次地理编码 + 一次普通驾车，最多 2 个成功请求，并显示实际 HTTP 调用数。
- 错误映射：Key无效、权限不足、额度不足、QPS超限、网络连接失败、查询超时、查询失败等；绝不伪造距离。
- Key 从 Credential Manager/DPAPI 读取，日志移除 Key、sig 和查询串秘密。
